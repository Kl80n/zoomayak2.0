# ЗооМаяк v7

Vite + React + TypeScript MVP интерфейса ЗооМаяка.

## Запуск локально

```bash
npm install
npm run dev
```

## Проверка

```bash
npm run typecheck
npm run build
```

## Vercel

Проект подготовлен для Vercel:

- Framework: Vite
- Build Command: `npm run build`
- Output Directory: `dist`

## Что есть в v7

- точный утверждённый master-логотип совета директоров как единый asset;
- настоящий QR с фирменным знаком в центре;
- QR-сканер с камерой и поддержкой URL / ZM-ID / микрочипа;
- компактная главная без повторяющихся блоков питомца;
- личный кабинет пользователя в шапке и на мобильном;
- цифровой паспорт, питомцы, здоровье, напоминания и SOS;
- раздел «Объявления» с отдельными вкладками:
  - продажа животных;
  - услуги для питомцев;
  - мои объявления;
- демонстрационная единая лента источников Avito / VK / Telegram + объявления ЗооМаяка;
- форма размещения собственного объявления;
- сохранение демо-данных в localStorage;
- светлая бело-зелёная и тёмная темы;
- адаптация для мобильных экранов.

### Важно про парсинг

В интерфейсе восстановлена архитектура единой ленты и отображение источников. Внешний live-парсинг Avito/VK/Telegram должен выполняться серверными адаптерами/API, а не напрямую из браузера. Это отдельный backend-этап.
